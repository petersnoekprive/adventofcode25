# adventofcode25

Ik werk met python 3.14.
Ik gebruik het script `pyenv` om te kunnen switchen tussen python versies. 

Het script `setup.py` kun je gebruiken om een nieuwe map aan te maken, en daarin vier template bestanden neer te zetten:
- day99a.py -> hierin komt jouw uitwerking van de eerste puzzel
- day99b.py -> tweede puzzel
- example99.txt -> de voorbeeld puzzel input
- input99.txt -> jouw persoonlijke input
Om `setup.py` te kunnen gebruiken, moet je met pip even gitpython installeren: `pip install gitpython` (dan worden de nieuw aangemaakte mappen en bestanden alvast gestaged).

De bestanden `example99.txt` en `input99.txt` zijn opgenomen in .gitignore zodat ze niet publiek beschikbaar komen (verzoek van advent of code).
